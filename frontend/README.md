# 足球导演前端 - Frontend

这是足球导演系统的前端部分，已经重构为模块化的文件结构。

## 文件结构

```
frontend/
├── index.html      # 主HTML文件
├── styles.css      # 所有CSS样式
├── script.js       # 所有JavaScript功能
└── README.md       # 说明文档
```

## 文件说明

### index.html
- 主HTML文件，包含页面结构和内容
- 引用外部的CSS和JavaScript文件
- 包含所有模态框和表单结构

### styles.css
- 包含所有CSS样式
- 分为以下主要部分：
  - 基础样式重置
  - 头部和导航样式
  - 表单和按钮样式
  - 比赛详情样式
  - 编辑功能样式
  - 响应式设计

### script.js
- 包含所有JavaScript功能
- 主要功能模块：
  - 页面导航
  - 比赛管理
  - 比赛详情编辑
  - 事件管理
  - 视频制作
  - 评论管理
  - 工具函数

## 使用方法

1. 直接在浏览器中打开 `index.html` 文件
2. 或者通过Web服务器访问（推荐）

## 功能特性

- ✅ 比赛管理（创建、查看、删除）
- ✅ 比赛详情编辑（内联编辑）
- ✅ 事件管理（添加、编辑、删除）
- ✅ 视频制作任务管理
- ✅ 评论编辑
- ✅ 响应式设计
- ✅ 现代化UI界面

## 技术特点

- 模块化文件结构
- 清晰的代码分离
- 易于维护和扩展
- 无外部依赖
- 纯HTML/CSS/JavaScript实现

- Firefox 55+

## 开发说明

如需修改样式，请编辑 `styles.css` 文件。
如需修改功能，请编辑 `script.js` 文件。
如需修改页面结构，请编辑 `index.html` 文件。
